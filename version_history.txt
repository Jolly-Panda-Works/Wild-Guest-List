1.34.0
- Mobile Portrait game screen layout reworked to match the new
  layout brief: Logo -> Turn/Round/Timer + Pause/Help/Guide (two
  rows) -> Standings/Log/Chat -> Opponents summary -> Party/Trash ->
  Queue -> Player Hand.
- Opponent summary rows moved above Party/Trash and simplified to
  avatar + name + a single deck-back count (deck + hand combined).
- Party/Trash buttons above the Queue restyled to match the
  Standings/Log/Chat rail buttons (bordered, icon + label in a row).

1.35.0
- Player's own Hand + Deck now sit side by side in one row (Deck to
  the right, never wrapping onto its own line), with the player's
  avatar + name shown as a single header line above that row —
  matching the "avatar/name on top, hand cards + deck in a row
  below" reference layout.
- .player-deck-info (avatar + name) moved out of #deckStack and into
  its own row inside #handArea; #deckStack is now the Hand+Deck row
  itself.

1.36.0
- Player Hand now sits flush at the bottom of the screen: #queueArea
  is the flexible element that grows to absorb all leftover vertical
  space between Party/Trash and the Hand, instead of shrink-wrapping
  to its own content and leaving a big empty gap below the Queue.
- Bigger Queue area also means a bigger drag-and-drop target, since
  the drop check (isOverQueueDropZone) already accepts any point
  inside #queueArea's box, not just directly on a slot.
- Queue slot size unified with the Player Hand's own card size (same
  clamp() values) instead of a separately-tuned smaller size.

1.36.5
- Removed the Power stat from Animal Ability Cards project-wide: the
  Card Guide grid tiles and detail popup (js/game/help.js,
  .help-card-power/.power-badge), the in-game ability guidance chip
  (js/ui/cardGuidance-ui.js, .guide-chip-power), and the tutorial's
  ability-examples slide (js/ui/tutorial-ui.js, .tut-ability-power)
  no longer display a numeric Power value.
- Cleaned up the now-obsolete "power" fields from data/tutorial.json's
  diagram data (never rendered by any diagram type) and dropped the
  dead .help-card-power/.power-badge/.guide-chip-power/.tut-ability-power
  CSS rules.
- Renamed the Card Guide modal title from "Animal Powers" to "Animal
  Abilities" (en/ar/tr; fa already used this wording) and reworded the
  tutorial's "A few power examples" diagram label to "A few ability
  examples".
- The underlying `power` field remains untouched as the load-bearing
  gameplay stat behind sorting, ability targeting, scoring, and AI
  evaluation (data/cardInfo.json, js/abilities/abilities.js,
  js/services/dataLoader.js) — as does the separate end-of-game/
  leaderboard "Power" score label, which is a distinct scoring feature,
  not part of the Animal Ability Cards. No gameplay behavior changed.
